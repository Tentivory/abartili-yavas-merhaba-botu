# Abartılı Yavaş Merhaba Botu

## Bu Proje Nedir?

Bu, insanlığın en büyük problemlerinden birini çözen devrim niteliğinde bir projedir: **Merhaba demek çok hızlı oluyor.**

Evet, duydunuz. Modern dünyada insanlar birbirine çok çabuk "merhaba" diyor. Bu kabul edilemez. Bu bot, merhaba demeyi **bilimsel olarak yavaşlatır**.

## Nasıl Çalışır?

1. Kodu çalıştırırsınız.
2. Bot düşünür.
3. Daha çok düşünür.
4. Sonunda merhaba der.

Gerçekten çalışır. Deneyin. (Sabır önerilir.)

## Kurulum

```bash
python merhaba_bot.py
```

Veya isimle:

```bash
python merhaba_bot.py Ahmet
```

## Bilimsel Katkılar

- Yavaşlık biliminin öncüsü.
- Zamanın değerini anlamanızı sağlar (beklerken).
- Hiçbir patates içermez. (Kullanıcı özel isteği.)

## Uyarı

Bu botu çalıştırmak hayatınızı değiştirebilir. Daha yavaş bir insan olabilirsiniz. Sorumluluk size aittir.
